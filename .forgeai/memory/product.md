# ForgeAI Product Description

## Overview

ForgeAI is a VS Code extension that provides AI-powered coding assistance using local LLMs via Ollama. It enables developers to write, refactor, and understand code without sending data to cloud APIs.

## Target Users

- Developers who want AI assistance without cloud dependency
- Teams requiring air-gapped or privacy-preserving development
- Users with limited internet connectivity
- Developers who prefer local model control and customization

## Core Features

1. **Chat Interface** — Natural language coding assistance in a VS Code panel
2. **Autonomous Agent Mode** — AI agents that can read, write, and execute code
3. **Spec-Driven Development** — Structured specs guide AI implementation
4. **UI/UX Architect Agent** — Professional design system generation
5. **RAG Knowledge Base** — Local vector database for codebase context
6. **Tool Registry** — Extensible tool system for agent capabilities
7. **Browser Capability** — Web research for current documentation and trends

## Product Goals

- Zero cloud API costs
- Privacy-first: no code leaves the local machine
- Fast response times via local inference
- Reliable, deterministic behavior through specs
- Professional-grade code quality

## Key Differentiators

- **Spec-driven architecture** vs prompt-driven competitors
- **Local-only execution** vs cloud-dependent tools
- **Multi-agent orchestration** vs single-agent assistants
- **Design-first approach** with UI/UX Architect Agent
